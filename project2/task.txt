1. OVERVIEW
-----------
This project contains two pieces of work built in one Flutter app:

  Task 1 - Interactive Counter UI   (lib/counter_page.dart)
  Task 2 - Weather Forecast App     (lib/weather_*.dart)

The app currently launches directly into the Weather Forecast screen.
The Task 1 counter screen is kept in the project as a separate page.


2. TASK 1 - INTERACTIVE FLUTTER UI  (lib/counter_page.dart)
-----------------------------------------------------------
Requirement (from task.txt): a screen with three horizontal sections that
adjusts to the screen size.

What was done:
  - Left section   : a red box (Container with Colors.red).
  - Middle section : a yellow box showing "Counter Value: N", starting at 0.
                     Wrapped in a GestureDetector, so each tap increases the
                     counter by 1 using setState().
  - Right section  : a box whose color changes with the counter:
                     green when the counter is even, blue when it is odd.
  - Layout         : a Row with three Expanded children, so the sections share
                     the width equally and adapt to any screen size.

Concepts used: StatefulWidget, setState, GestureDetector, Row, Expanded.


3. TASK 2 - WEATHER FORECAST APP
--------------------------------
A screen that fetches live weather data from the free Open-Meteo API
(https://api.open-meteo.com) and displays it for a selected city.

Features:
  - City dropdown with 5 predefined cities of Bangladesh:
    Chattogram (default), Dhaka, Sylhet, Khulna, Rajshahi.
  - Shows current temperature, weather description, weather icon, humidity,
    wind speed, and today's minimum and maximum temperature.
  - Loading state  : a progress indicator while the data is being fetched.
  - Error state    : a "Could not load weather data" message with a Retry
                     button (handles no internet / server errors).
  - Request timeout of 10 seconds.
  - Changing the city automatically fetches new data.

Concepts used: HTTP requests, async/await, Future, FutureBuilder,
JSON parsing, model class, separation of UI / service / model.


4. FILE STRUCTURE
-----------------
  lib/main.dart             App entry point. Sets the title ("Weather App"),
                            the red-seeded color theme, and opens WeatherScreen.
  lib/weather_screen.dart   UI of the weather page (dropdown, FutureBuilder,
                            weather card, error view, retry button).
  lib/weather_service.dart  WeatherService class: builds the Open-Meteo URL,
                            sends the HTTP GET request, checks the status code.
  lib/weather_model.dart    Weather model: fromJson() parsing, converts the WMO
                            weather code into readable text and a Flutter icon.
  lib/counter_page.dart     Task 1 counter screen (CounterPage).
  test/widget_test.dart     Unit test for Weather.fromJson using fake JSON data
                            (no internet needed).
  task.txt                  Original description of Task 1.
  pubspec.yaml              Dependencies: flutter, cupertino_icons, http.
  android/, ios/, web/      Platform folders generated by Flutter.
